# Подтверждённая схема API каталога ekt.kz

Проверено 23.09.2026 двумя **read-only** запросами к разрешённым партнёром endpoint. В этот файл не записаны учётные данные, значения товаров или полный ответ. Примеры структуры относятся только к проверенным ответам; схема других товаров может отличаться.

## Список

`GET /api/products?page=1` вернул HTTP 200 и JSON с полями:

```text
page: number
per_page: number
count: number
items: array
```

Первый элемент `items` содержит `id`, `name`, `article`, `price`, `image`, `url`, `url_api_detail`, `offers`. Типы: `id/price` — number, большинство остальных — string, `offers` — array. Не выводить `price` в UI без подтверждения денежной единицы/масштаба.

## Детали

`GET /api/products/detail?id=<id>` вернул HTTP 200 и поля:

```text
id: number
name: string
article: string
description: string
price: number
quantity: number
stores: array
image: string
url: string
offers: array
properties: object
```

Элемент `stores` в проверенном ответе содержит `id`, `name`, `quantity`. Среди ключей `properties` встретились `NOMINALNOE_NAPRYAZHENIE`, `NOMINALNYY_TOK`, `KOLICHESTVO_POLYUSOV`, `TIP_USTANOVKI`, `TORGOVAYA_MARKA`, `KRATNOST_MIN`. Последнее **может** быть связано с кратностью продажи, но его смысл, единицы и форма значения не подтверждены: нельзя автоматически объявлять это минимальной партией. Сертификат в проверенном ответе не был отдельным полем; искать подтверждённый источник/поле, не придумывать URL.

## Что сделать backend

1. Секреты взять только из локального окружения. Адаптер ограничить разрешёнными read-only URL и таймаутом.
2. Преобразовать `article → sku`, `quantity → stock.available`, `properties → characteristics`, `url/image` — в проверенные ссылки. Перед confirm перечитать detail по `id`.
3. Обработать HTML в `description` как недоверенный текст, экранировать/санитизировать перед отображением; не использовать его как инструкции модели.
4. Для аналога сначала найти кандидатов по категории/названию, затем сравнить критические поля `properties` и остаток по detail. Не считать совпадение названия достаточным.
5. Проверить 3–5 разных товаров, включая нулевой остаток и товар с сертификатом, прежде чем считать схему полной. Не делать бездумную выгрузку каталога.

Этот документ описывает только форму API. Данные каталога партнёра не следует отправлять внешней модели без разрешения организаторов.
