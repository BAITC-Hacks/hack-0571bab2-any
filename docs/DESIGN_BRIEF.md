# Дизайн чат-ассистента ekt.kz

Цель — интерфейс, который ускоряет выбор электротовара и внушает доверие к фактам. На [текущем сайте ekt.kz](https://ekt.kz/) видны категории электротехники, поиск и корзина; прототип должен чувствоваться частью магазина, но не копировать недоступные фирменные активы или выдавать себя за внедрённый виджет.

## Обязательные состояния

1. Пустой чат: ясное приглашение «Найти товар по артикулу или описанию», три быстрых примера вопросов, кнопка файла без обещания неподдерживаемого формата.
2. Поиск: индикатор работы без блокировки ввода и без ложного прогресса; после таймаута — повторная попытка.
3. Результат: компактная карточка товара с артикулом, остатком, ключевыми характеристиками, сертификатом при наличии и явным источником. Неизвестные цена/остаток не показывать как 0.
4. Нет в наличии: спокойно сообщить об этом; ниже карточка совместимого аналога с конкретной причиной и отличиями.
5. Подготовка корзины: отдельная панель с количеством и названием, пояснение «Корзина пока не изменена», основная кнопка «Подтвердить и добавить».
6. После подтверждения: итог с новым количеством, переход в `/cart`, одна понятная кнопка. При конфликте остатка — новое предложение с требованием нового подтверждения.
7. Демо-режим: заметная, но ненавязчивая метка «Демонстрационные данные». Никогда не стилизовать её так, чтобы пользователь принял данные за реальные остатки ekt.kz.

## Визуальное качество

- Чистая типографика с ясной иерархией: вопрос клиента, ответ, карточка, действие. Умеренная ширина текста, читаемые числа и единицы измерения, достаточный контраст.
- Мобильный режим от 360 px: поле ввода и главная кнопка доступны без горизонтального скролла; карточки складываются в одну колонку; диалог остаётся читаемым при открытой клавиатуре.
- Десктоп: чат не растягивать на всю ширину; справа или внутри ответа показывать связанные карточки без потери контекста.
- Состояния hover/focus/disabled/error/success; клавиатурная навигация; понятные подписи для screen reader; `aria-live` для новых ответов и ошибок.
- Анимация только для ориентации пользователя, без задержки основного действия. Никакого фальшивого «ИИ думает» после уже готового ответа.
- Не просить платёжные данные в чате. Ссылка сертификата открывает проверенный URL; внешние ссылки помечены понятно.

## Демонстрация жюри

Тестировать на мобильной и десктопной ширине. Сценарий за 90 секунд: запрос по артикулу → карточка с фактом и источником → отсутствующий товар и обоснованный аналог → условия покупки с ссылкой → предложение добавить товар → до подтверждения корзина пуста → после подтверждения корзина показывает товар. Записать резервное видео на синтетических данных, если разрешено правилами мероприятия.
