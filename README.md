# HackAlem AI — ekt.kz assistant

Приватный репозиторий команды для кейса «ИИ-ассистент-консультант и помощник для сайта ekt.kz».

## Что делает прототип

Покупатель задаёт вопрос о товаре, аналогах или условиях покупки в чате. Backend ищет несколько возможных позиций, перечитывает их текущие карточки и отвечает только подтверждёнными фактами. Для документа он локально выделяет артикулы с явным количеством; для фото после отдельного согласия предлагает возможные совпадения, которые нужно сверить с маркировкой. Добавление в **демо-корзину** требует отдельного подтверждения и повторной проверки остатка. Русский и казахский поддерживаются в API; интерфейс казахского языка и загрузки вложений должен быть завершён в ветке `frontend`.

## Архитектура и технологии

Браузерный интерфейс: React 19, TypeScript и Vite 7. В разработке Vite направляет `/api/*` к Fastify API на Node.js 20.16+ и TypeScript. API держит сессию, CSRF-защиту, ожидающее предложение и демо-корзину в памяти одного процесса. Поэтому одна сессия и её корзина работают на одном экземпляре сервера и исчезают при перезапуске.

Каталог по умолчанию синтетический. При разрешённом live-режиме сервер читает только партнёрские HTTPS endpoints списка и карточки ekt.kz через Basic Auth. Локальный приватный индекс хранит артикул, название и ID для быстрого поиска; перед ответом и подтверждением корзины API перечитывает карточку, чтобы проверить свойства и остаток. Фото обрабатывает Sharp с удалением метаданных; текстовые PDF — pdfjs-dist, DOCX/XLSX — ограниченный локальный разбор. Содержимое документов не отправляется внешнему ИИ.

Внешний OpenAI Responses API необязателен: простые запросы обрабатываются правилами, поиск по описанию может использовать GPT-6 Luna, запросы по нескольким категориям — GPT-6 Sol, проект дома — GPT-6 Astra. Анализ фото начинает Sol и при необходимости один раз переходит к Astra. Моделям передаётся короткий запрос и несколько кандидатов, а товарные факты в ответе выводятся из карточек каталога. Есть лимиты вызовов и безопасный режим без модели. NVIDIA в текущем прототипе не вызывается. Реального API корзины ekt.kz и развёрнутой публичной версии пока нет.

3. [Полный план](docs/00_ПОЛНЫЙ_ПЛАН_HackAlem_ekt.md), [API-контракт](docs/03_КОНТРАКТ_API.md), [схема каталога](docs/CATALOG_API_SHAPE.md), [источники условий покупки](docs/BUYING_TERMS_SOURCES.md) и [дизайн-бриф](docs/DESIGN_BRIEF.md) являются общими. По одному [заданию backend](docs/01_ЗАДАНИЕ_BACKEND_Codex.md) и [frontend](docs/02_ЗАДАНИЕ_FRONTEND_Codex.md) можно сверять свою часть.
4. К `xx:50` каждого часа каждый отправляет содержательный проверенный коммит в свою ветку. Финальная интеграция и сдача делаются до официального дедлайна.

Ключи и доступ партнёра остаются только в локальной конфигурации backend. `.env.example` содержит имена полей без значений. API корзины ekt.kz, минимальную партию и спорный порог бесплатной доставки ещё требуется уточнить у партнёра; прототип не должен выдавать демо-данные за боевые.

## Локальный запуск прототипа

Нужен Node.js 20.16+. Backend находится в ветке `backend`, frontend — в отдельной ветке `frontend`. Пока ветки не слиты, запускайте их в двух рабочих копиях репозитория. В объединённой копии команды выполняются в соответствующих каталогах.

Терминал API, из ветки `backend`:

```sh
cd apps/api
npm ci
WEB_ORIGIN=http://localhost:5173 npm run dev
```

Терминал UI, из ветки `frontend`:

```sh
cd apps/web
npm ci
npm run dev
```

Откройте `http://localhost:5173/` для запросов к API через Vite-прокси. Отдельный mock-интерфейс доступен по `http://localhost:5173/?demo=1`; он использует собственные синтетические данные и не проверяет backend. `apps/api/README.md` описывает сессию, CSRF и ограничения, `apps/web/README.md` — интерфейс и mock-режим. Установка ключей для демо не требуется.

## Проверка

```sh
cd apps/api
npm test
npm run build
```

```sh
cd apps/web
npm run build
```

В API-режиме проверьте артикулы `ABC-123` (остаток 4), `ABC-000` (остаток 0 и аналог `ABC-124`), вопрос об оплате и доставке, затем `Добавь 2 ABC-123`. До отдельного подтверждения `/cart` остаётся пустой; после подтверждения показывает 2 шт. и сохраняет их при обновлении страницы. Для казахского API-чата передайте `locale: "kk"`; страница `/cart?lang=kk` показывает демо-корзину на казахском. Данные каталога здесь синтетические. Проверенных ссылок на сертификаты и единиц цены нет; backend честно сообщает об отсутствии этих данных. Корзина прототипа хранится в памяти API и не является корзиной ekt.kz.

Основной браузерный сценарий проверен в локальной копии, объединяющей `backend` и `frontend`, без коммита слияния: факты, аналог, условия, предложение без изменения корзины и подтверждение 2 шт. Исправление восстановления сессии уже находится в `frontend` (`f2a72ea`); объединённая копия прошла `npm ci`, сборку обоих приложений, API-тесты и браузерный сценарий. Для фото backend принимает JPEG/PNG с отдельным согласием и проверяет возможный товар по свежей карточке, но доступная ветка `frontend` пока не содержит интерфейса загрузки.
