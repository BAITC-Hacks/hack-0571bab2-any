# HackAlem AI — ekt.kz assistant

Приватный репозиторий команды для кейса «ИИ-ассистент-консультант и помощник для сайта ekt.kz».

## Начать работу вдвоём

1. Оба участника читают [одно общее задание для Codex](docs/TEAM_CODEX_PROMPT.md) и [правила репозитория](AGENTS.md).
2. Нурали работает в ветке `backend`, напарник — в `frontend`. Отличается только последняя строка общего промпта.
3. [Полный план](docs/00_ПОЛНЫЙ_ПЛАН_HackAlem_ekt.md) и [API-контракт](docs/03_КОНТРАКТ_API.md) являются общими. По одному [заданию backend](docs/01_ЗАДАНИЕ_BACKEND_Codex.md) и [frontend](docs/02_ЗАДАНИЕ_FRONTEND_Codex.md) можно сверять свою часть.
4. К `xx:50` каждого часа каждый отправляет содержательный проверенный коммит в свою ветку. Финальная интеграция и сдача делаются до официального дедлайна.

Ключи и доступ партнёра остаются только в локальной конфигурации backend. `.env.example` содержит имена полей без значений. API корзины ekt.kz и подтверждённые условия покупки ещё требуется уточнить у партнёра; прототип не должен выдавать демо-данные за боевые.

Этот README является стартовой инструкцией и должен быть дополнен фактическими командами запуска, архитектурой и результатами после реализации приложения.
