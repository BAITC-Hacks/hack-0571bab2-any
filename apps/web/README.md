# Frontend прототипа ekt.kz

React 19, TypeScript и Vite. Код находится в `apps/web`. Используется общий контракт [`docs/03_КОНТРАКТ_API.md`](../../docs/03_КОНТРАКТ_API.md), без ключей в браузере.

## Запуск

```bash
cd apps/web
npm ci
npm run dev
```

Откройте `http://localhost:5173/`. В режиме API запросы `/api/*` проксируются на `http://127.0.0.1:3001` (значение можно изменить через `VITE_API_PROXY_TARGET`). Браузер сохраняет сессию через cookie. Клиент получает CSRF-токен из `GET /api/cart` и отправляет его на каждый POST. Для отдельной проверки интерфейса без backend откройте `http://localhost:5173/?demo=1`: в этом режиме каталог и корзина полностью синтетические, данные хранятся в `sessionStorage` вкладки и **не связаны с ekt.kz**. Для выхода из mock режима закройте вкладку или удалите `ekt_frontend_mock` в её `sessionStorage`.

Для совместного локального запуска откройте другой терминал: `cd apps/api && npm ci && WEB_ORIGIN=http://localhost:5173 npm run dev`. Затем откройте обычный `/` без `?demo=1`. Серверный демо-каталог содержит артикулы `ABC-123` (4 шт.), `ABC-000` (нет в наличии) и аналог `ABC-124`. После перезапуска API незавершённое предложение теряется: frontend показывает ошибку и предлагает подготовить новое; прежняя корзина сервера тоже не сохраняется.

## Проверка frontend

```bash
npm run build
```

В `?demo=1` проверьте сценарии:

1. `DEMO-LED-12` показывает характеристики и синтетический остаток 4 шт., без вымышленной цены или сертификата.
2. `DEMO-LED-OLD` показывает нулевой остаток, аналог и причину с ограничением совместимости.
3. Вопрос об оплате, доставке и минимальной партии даёт ссылку на публичные условия и говорит, что минимум не подтверждён.
4. `Добавь 2 шт. DEMO-LED-12` создаёт предложение. `/cart` остаётся пустой до отдельного клика.
5. «Подтвердить и добавить» меняет корзину один раз; ссылка `/cart` показывает 2 шт. Повторный быстрый клик не добавляет вторую пару.
6. Следующая попытка добавить 3 шт. получает конфликт остатка и предлагает подготовить новое предложение на 2 шт.

Frontend не обрабатывает вложения и не заявляет интеграцию с корзиной сайта. Эти возможности зависят от серверного API и разрешений партнёра.
