# Визуальный прототип ekt.kz

Ветка `mockup-web` содержит макет сайта для интеграции в рабочую ветку `frontend`. В `frontend` уже есть API-клиент и настройка CSRF, поэтому переносите дизайн и компоненты выборочно, сохраняя рабочую логику партнёра.

## Запуск рядом с другим frontend

Из `apps/web`:

```sh
npm install
API_PROXY_TARGET=http://127.0.0.1:3107 npm run dev -- --port 5174 --host 127.0.0.1
```

Для работы помощника нужен API этого проекта, запущенный с `PORT=3107` и `WEB_ORIGIN=http://127.0.0.1:5174`. Откройте `http://127.0.0.1:5174/`. Обычный `npm run dev` использует порт `5173` и проксирует `/api` на `3001`.

## Что воспроизведено

- Общая шапка, поиск, меню каталога, мобильная и десктопная сетка, подвал.
- Главная с баннерами и 12 категориями; 134 подраздела из публичного каталога.
- Шаблоны товарной выдачи и карточки с 8 образцами из публичных страниц. Цена и остаток в локальной копии не заявляются как актуальные.
- Новости, отдельные новости, «О компании», условия оплаты и доставки, навигационные страницы.
- Демонстрационная корзина и помощник, подключённые к `/api`. Добавление происходит только после отдельного подтверждения.

## Ограничения

Это визуальный прототип для хакатона, а не копия серверной части ekt.kz. Полный товарный каталог, личный кабинет, оформление заказа, подписка и реальные избранное/сравнение здесь не подключены. Для неподдержанных страниц и актуальных условий есть ссылки на официальный сайт. Демо-корзина хранится в памяти API и сбрасывается при его перезапуске.
